# Padel Saturday Sniper 🎾

Следит за группой Padel PORTAL на racket.id и пытается записать аккаунт, когда появляется свободное место на ближайшую субботу.

## Что исправлено

- GitHub Actions запускается по часовому поясу `Europe/Lisbon` в понедельник в 09:55, чтобы успеть подготовить браузер до окна 10:00–13:00. Код блокирует запись вне этого окна.
- Внутри запущенного процесса страница проверяется каждую секунду; полная перезагрузка происходит раз в 15 секунд. Это снижает задержку и не требует отдельных запусков Actions каждые пять минут.
- Событие должно совпадать с датой ближайшей субботы. При полной игре, кнопке резерва или неясном результате бот не сообщает об успешной записи.
- Запись считается успешной, только когда после перезагрузки страницы видно состояние участника.
- Состояние авторизации сохраняет IndexedDB, где racket.id может хранить сессию Firebase. Файл `storageState.json` остаётся локальным и игнорируется Git.

GitHub предупреждает, что запланированные запуски Actions иногда задерживаются или пропускаются при высокой нагрузке. Бот не может компенсировать запуск после 13:00. Для меньшей задержки его нужно держать запущенным на постоянно работающем компьютере или VPS.

## Настройка GitHub Actions

1. Установите зависимости и сохраните сессию:
   ```bash
   npm ci
   npm run capture
   ```
   В открывшемся окне войдите в racket.id. Когда страница группы загрузится, вернитесь в терминал и нажмите Enter.
2. Загрузите сохранённую сессию в секрет репозитория `STORAGE_STATE_B64`:
   ```bash
   base64 < storageState.json | tr -d '\\n'
   ```
   Скопируйте вывод в **Settings → Secrets and variables → Actions → New repository secret**. Не публикуйте его в коде, issue или чате: это активная сессия аккаунта.
3. По желанию добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` для уведомлений.
4. В Actions вручную запустите workflow с режимом `check`. Он проверяет вход и страницу ближайшей субботы, не нажимая запись. Для обычной работы расписание запускает режим `live` автоматически.

Если сессия истекла, повторите вход через `npm run capture` и обновите секрет `STORAGE_STATE_B64`.

## Локальный запуск

```bash
npm ci
npm run capture
npm run check                 # только проверка, без записи
MODE=live HEADLESS=false npm run snipe
```

Ручной запуск `live` разрешает запись только по понедельникам между 10:00 и 13:00 по Лиссабону. Оплату бот не выполняет. Если сайт показывает резерв или оплату, действие требует ручной проверки.
